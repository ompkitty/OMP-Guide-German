# Verwendung – Grundlagen

## OMP starten

Öffne ein Terminal und führe aus:

```sh
omp
```

OMP startet dann eine interaktive Sitzung, in der du deine Aufgaben eingibst.

Du kannst auch direkt einen Auftrag mitgeben:

```sh
omp "Liste alle TypeScript-Dateien in src auf"
```

## Grundlegender Arbeitsablauf

1. **Aufgabe beschreiben** – du formulierst, was erledigt werden soll.
2. **Agent arbeitet** – OMP liest, sucht, ändert Dateien und führt bei Bedarf Befehle aus. Dabei erklärt er verständlich, was er tut.
3. **Ergebnis prüfen** – du siehst die Änderungen und das Ergebnis und gibst die nächste Anweisung.

Bei Aktionen, die etwas verändern (zum Beispiel Befehle oder Dateiänderungen), kann OMP – je nach Einstellung – vorher um Bestätigung bitten.

## Sitzungen fortsetzen

Angefangene Arbeit geht nicht verloren:

- `omp --continue` (kurz `-c`) setzt die **letzte Sitzung** fort.
- `omp --resume` öffnet die Auswahl gespeicherter Sitzungen.

## Wichtige Grundbefehle

| Befehl | Bedeutung |
| --- | --- |
| `omp` | Interaktive Sitzung starten. |
| `omp "Aufgabe"` | Sitzung direkt mit einer Aufgabe starten. |
| `omp -p "Aufgabe"` | Aufgabe ausführen, Ergebnis ausgeben und beenden (ohne Oberfläche). |
| `omp --continue` | Letzte Sitzung fortsetzen. |
| `omp --help` | Hilfe zu Befehlen und Optionen anzeigen. |
| `omp --version` | Installierte Version anzeigen. |

## Modell auswählen

Über Optionen kannst du bestimmen, welches Modell arbeitet:

- `--model <modell>` – das Modell für die Sitzung wählen.
- `--smol <modell>` – ein schnelles, kleines Modell für leichte Aufgaben.
- `--slow <modell>` – ein gründliches Modell für anspruchsvolle Aufgaben.
- `--plan <modell>` – ein Modell zum Planen.

Mehr dazu im Abschnitt [ModelRoles](../settings/modelroles).

## Slash-Kommandos

Innerhalb einer Sitzung gibt es Kommandos, die mit `/` beginnen. Einige Beispiele:

- `/settings` – Einstellungen öffnen.
- `/review` – Änderungen durchsehen und bewerten lassen.
- `/share` – eine Sitzung über einen Link teilen.

Der Funktionsumfang kann je nach Version variieren; weitere Kommandos zeigt die Hilfe innerhalb der Sitzung.

:::tip
Der beste Weg zum Einstieg: `omp` starten und eine kleine, konkrete Aufgabe formulieren – etwa „Erkläre mir, wie diese Datei funktioniert“.
:::
