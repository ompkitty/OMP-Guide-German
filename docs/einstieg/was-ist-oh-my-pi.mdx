# Was ist Oh My Pi?

**Oh My Pi** – kurz **OMP** – ist ein Coding-Agent für das Terminal. Ein Coding-Agent ist ein KI-Assistent, der dich direkt bei der Arbeit an Software unterstützt: Er liest und durchsucht Code, ändert Dateien, führt Programme aus und erklärt dir Zusammenhänge. Die eigentliche Arbeit übernimmt dabei ein in Rust geschriebener Kern, der auf macOS, Linux und Windows läuft.

## Welchen Zweck erfüllt OMP?

OMP soll alltägliche Entwicklungsaufgaben im Terminal übernehmen:

- Code verstehen, durchsuchen und erklären
- Dateien ändern und Refactorings durchführen
- Programme, Tests und Skripte ausführen
- Fehler suchen – auch mit einem echten Debugger
- größere Aufgaben parallel an „Subagenten“ verteilen

Die Oberfläche ist fest in deine Werkzeuge eingebunden: Was deine Entwicklungsumgebung (IDE) über dein Projekt weiß, kann auch der Agent nutzen.

## Für wen ist OMP gedacht?

OMP richtet sich an Entwicklerinnen und Entwickler, die einen leistungsfähigen KI-Assistenten direkt im Terminal oder im Editor einsetzen möchten. Du brauchst dafür keine besondere Infrastruktur: OMP wird lokal installiert und verbindet sich mit dem Modell bzw. Anbieter deiner Wahl.

## Grundlegende Möglichkeiten im Überblick

OMP bietet unter anderem:

- **Dateien & Suche** – Dateien lesen, durchsuchen und über Such- und Dateimuster-Werkzeuge finden.
- **Code ändern** – präzise Änderungen und strukturelle Umformungen vornehmen.
- **Code ausführen** – Shell, Python und JavaScript direkt in der Sitzung ausführen.
- **IDE-Funktionen** – Navigation und Refactorings über Language Server (LSP) sowie Schritt-für-Schritt-Debugging.
- **Subagenten** – Aufgaben parallel an mehrere Helfer verteilen.
- **Konfigurierbarkeit** – Modelle, Rollen und die Darstellung an den eigenen Geschmack anpassen.
