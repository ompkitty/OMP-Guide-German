# Installation

Wähle den Installationsweg, der zu deinem System passt.

## macOS und Linux

Führe in deinem Terminal aus:

```sh
curl -fsSL https://omp.sh/install | sh
```

## Homebrew

```sh
brew install can1357/tap/omp
```

## Bun

```sh
bun install -g @oh-my-pi/pi-coding-agent
```

## Nix

```sh
# Ohne Installation ausprobieren
nix run github:can1357/oh-my-pi

# In das aktive Profil installieren
nix profile install github:can1357/oh-my-pi
```

## Windows (PowerShell)

```powershell
irm https://omp.sh/install.ps1 | iex
```

:::info[Windows / PowerShell 5.1]
Auf manchen Windows-Systemen kann es mit Windows PowerShell 5.1 zu Problemen bei der Installation kommen. Einzelheiten dazu findest du unter [Windows / PowerShell](./windows-powershell).
:::

## Installation prüfen

Nach der Installation kannst du prüfen, ob OMP verfügbar ist:

```sh
omp --version
```

Wenn hier eine Versionsnummer erscheint, ist die Installation abgeschlossen. Ein erster Start gelingt mit:

```sh
omp
```

Mehr dazu unter [Verwendung](../verwendung/grundlagen).
