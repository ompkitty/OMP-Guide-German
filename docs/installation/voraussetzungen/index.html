Voraussetzungen

Bevor du OMP installierst, prüfe kurz diese Punkte.

Unterstützte Betriebssysteme​

OMP läuft auf:

  • macOS
  • Linux
  • Windows

Terminal​

Du brauchst ein Terminal, in dem du Befehle ausführen kannst. Geeignet sind zum Beispiel:

  • macOS: Terminal oder iTerm
  • Linux: eine gängige Terminal-Anwendung
  • Windows: Windows Terminal oder PowerShell 7 (empfohlen)

Internetverbindung​

Für die Installation wird eine Verbindung zum Internet benötigt, um das Paket herunterzuladen.

Zusätzliche Werkzeuge​

Je nach Installationsweg kann zusätzliche Software erforderlich sein:

  • Bun in Version 1.3.14 oder neuer, wenn du OMP über Bun installierst.
  • Homebrew oder Nix, wenn du den jeweiligen Paketmanager verwendest.

Die vorkompilierten Versionen von OMP benötigen keine zusätzliche Laufzeitumgebung und werden direkt als Programm installiert.

tipp

Für Windows-Nutzer gibt es eine bekannte praktische Erfahrung zur Wahl von PowerShell 7 – Details findest du unter Windows / PowerShell.
