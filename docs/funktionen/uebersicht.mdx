# Verfügbare Funktionen

OMP bringt viele Funktionen mit. Hier findest du einen Überblick – jeweils kurz erklärt, damit du verstehst, wofür die Funktion gut ist.

## Dateien, Suche und Änderungen

| Funktion | Wofür |
| --- | --- |
| **Lesen** | Dateien, Ordner, Archive und Webseiten ansehen und zusammenfassen. |
| **Suchen** | Projekte nach Text oder Mustern durchsuchen. |
| **Dateisuche** | Dateien anhand von Namensmustern finden. |
| **Bearbeiten** | Gezielt einzelne Stellen in Dateien ändern. |
| **Struktur-Änderungen** | Code-Umformungen über die tatsächliche Struktur (nicht nur Text). |

## Ausführen

| Funktion | Wofür |
| --- | --- |
| **Shell** | Befehle im Terminal ausführen – direkt aus der Sitzung. |
| **Python & JavaScript** | Python- und JavaScript-Code in einer dauerhaften Sitzung ausführen. |

## IDE-Integration

| Funktion | Wofür |
| --- | --- |
| **Language Server (LSP)** | Navigation, Umbenennen und Refactorings wie in einer IDE. |
| **Debugger** | Programme schrittweise ausführen, Haltepunkte setzen, Variablen prüfen. |

## Zusammenarbeit und Koordination

| Funktion | Wofür |
| --- | --- |
| **Subagenten** | Größere Aufgaben an mehrere Helfer parallel verteilen. |
| **Advisor** | Ein zweites Modell beobachtet deine Arbeit und gibt Hinweise. |
| **Teilen** | Sitzungen per Link teilen und zusammen daran arbeiten. |

## Internet und Desktop

| Funktion | Wofür |
| --- | --- |
| **Web-Suche** | Im Internet recherchieren und Quellen anzeigen. |
| **Webseiten lesen** | URLs, PDFs und andere Inhalte direkt einlesen. |
| **Browser** | Einen echten Browser automatisiert steuern. |

## Eigene Anpassung

| Funktion | Wofür |
| --- | --- |
| **Regeln** | Festlegen, woran sich der Agent bei deiner Arbeit halten soll. |
| **Erinnerung** | OMP merkt sich Wissenswertes über dein Projekt zwischen den Sitzungen. |
| **Designs & Rollen** | Darstellung und Modellzuordnung anpassen. |
